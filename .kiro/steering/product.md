# Product Overview

AI-Powered Quiz Generator and Assessment System - An online platform that enables teachers to automatically create quizzes using artificial intelligence.

## Core Features

### For Teachers
- Upload learning materials (PDF, Word, PowerPoint, text files, or links)
- AI engine analyzes content and generates multiple-choice questions automatically
- Configure quiz settings: title, duration timer, expiration date/time, number of questions
- Generate unique quiz access codes for easy sharing
- View comprehensive analytics: class average, highest/lowest scores, individual performance
- Export results as PDF or Excel

### For Students
- Access quizzes via unique code and school information
- Randomized questions from quiz pool (different questions per student, same correct answers)
- Countdown timer with auto-submission
- Immediate score feedback (if enabled)
- Quiz validation (checks if active and not expired)

## Key Benefits
- Promotes academic integrity through question randomization
- Saves teacher preparation time with AI-generated questions
- Flexible, content-relevant assessments
- Automated grading and result tracking
